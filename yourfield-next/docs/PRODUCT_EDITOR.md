# 产品可视化编辑器运营手册

本手册面向运营同学，说明 Payload 后台 `products` 集合的新产品可视化编辑器用法。

## 入口

1. 启动本地一体化服务：`pnpm dev`。
2. 打开 `/admin/collections/products`。
3. 新建或编辑任意产品，默认进入“产品可视化编辑器”。
4. 如需使用 Payload 原生表单，点击顶部“经典表单”，或在 URL 后追加 `?view=classic`。

## 顶部工具栏

- **语言切换**：`ZH / EN / RU` 会通过 URL `locale` 参数切换 Payload 当前语言。
- **保存状态**：显示“已保存 / 未保存 / 保存中”，来自 Payload form state。
- **必填徽章**：有必填项错误时显示数量，点击会打开第一个问题所在区块。
- **运营**：打开运营字段抽屉，维护 SKU、slug、标签、排序、SEO 等字段。
- **预览 / 编辑**：切换画布预览模式；预览模式会隐藏空区块的添加按钮。
- **经典表单**：进入 Payload 原生编辑表单，适合上传、关系字段、富文本等复杂字段。
- **前台预览**：打开当前产品对应的前台预览链接。
- **发布**：调用 Payload 表单提交，并覆盖 `_status=published`。

## 画布区块

画布按前台详情页顺序排列：

1. 主图与简介
2. 商品介绍
3. 核心卖点
4. 规格参数
5. 尺码对应表
6. 应用场景
7. 详情页图组
8. 资料与认证状态
9. 洗护与维护
10. 常见问题
11. 运营字段（从工具栏进入）

点击任何已展示区块会打开对应抽屉；空区块会显示“添加”按钮。空区块不会在前台详情页渲染。

## 图片数量

产品主图 `images` 与详情页图组 `visualGroups[].images` 已移除 20 张上限；如运营需要上传 30+ 张图片，请使用经典表单中的 Payload 原生上传控件完成。

## 经典表单逃生口

当遇到以下情况时，请使用“经典表单”：

- 需要批量上传或替换媒体文件。
- 需要维护关系字段（产品大类、行业、FAQ、关联产品）。
- 需要编辑复杂嵌套数组。
- 画布抽屉无法覆盖的 Payload 原生字段。

## 发布检查清单

发布前至少检查：

- 产品名称、产品编号、产品大类已填写。
- 主图和详情页图组图片可用。
- 中英俄三语必要文本已填写或确认可留空。
- SEO 标题/描述已填写。
- 前台预览页内容与后台画布一致。
- 如有 30+ 图片，经典表单保存后重新打开确认数量未被截断。

## 技术说明

- 自定义编辑器通过 `Products.admin.components.views.Edit.Default.Component` 注册。
- 默认编辑页仍由 Payload 的 edit view/Form 包裹；编辑器通过 `useFormFields`、`useField`、`useForm` 读取与提交 Payload form state。
- `?view=classic` 直接渲染 Payload 默认 collection edit view，不绕过 Payload 原生保存、校验、版本和 autosave 流程。
