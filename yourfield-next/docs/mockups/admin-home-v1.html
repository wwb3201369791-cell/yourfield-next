本版完整优化点对照

  • 顶部建筑横幅：取消，节省约 280px 首屏空间，hero 区直接承载欢迎语 + 核心数字 + CTA。
  • KPI 卡：去掉右上角装饰插画与"点击查看"常驻按钮；单一图标 + 大数字成为视觉中心，hover 浮现"查看 →"。
  • 趋势胶囊：与数字 baseline 对齐；颜色统一为升=绿、降=红、平=灰。
  • 待办胶囊：severe 改为纯红底白字靠对比度强调；warning/info 用浅色底，避免噪声。
  • 健康度面板：信息层减少（去掉冗余边框线），数字层级化排版。
  • 热门搜索：把"零结果"关键词标红（数字 + 右侧文案双色提示），让运营一眼看到要补内容的词。
  • 趋势图：图例改为可切换 segmented 控件；选中点的辅助线与多色标记同时显示；Tooltip 用 navy 边线 + 圆点对应色板。
  • 最近询盘：状态徽章改为色块（新=红、进=蓝、完=绿）；空状态用更友好的小插图 + 一句话提示；hover 整行高亮 + 时间次要色。
  • 集合入口：从大尺寸插画卡（148px 高）改成小图标徽章 + 标题 + 一句话提示的紧凑卡（约 76px 高），单行展示 6 张；卡片高亮色对应集合属性。
  • 字重层级：标签 600 / 正文 500 / 数字 800，让粗细承担信息层次而不是颜色。
