# 产品资料拆分结果

这些文件从 Word 文档内部直接提取：

- `按产品分类/`：总整理目录，按品类 / 系列 / 产品三级存放，每个产品一个文件夹。
- `images/`：DOCX 内嵌原图，来自 `word/media`，不是截图。
- `商品说明.md`：按文档正文顺序提取的可读商品说明。
- `商品说明.json`：结构化文本与图片引用，方便后续程序导入。
- `图片清单.csv`：原图文件清单与校验信息。
- `图片引用关系.md`：图片在正文中的引用位置和附近文字。
